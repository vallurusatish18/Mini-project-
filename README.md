# Mini Project - Global COVID-19 Interactive Dashboard

## 📌 Project Overview

This project is a **Global COVID-19 Interactive Dashboard** developed using **Python** and **Plotly** for data visualization. The dashboard provides detailed country-wise analysis of COVID-19 statistics including total cases, deaths, recoveries, testing rates, and active cases.

The project demonstrates how data analytics and visualization techniques can be used to understand pandemic trends effectively through interactive charts and maps.

---

# 🚀 Features

* Interactive Plotly Dashboard
* Country-wise COVID-19 Analysis
* Top Countries by Cases and Deaths
* Global Choropleth Map Visualization
* Testing and Recovery Analysis
* Active Cases Dashboard
* Interactive Scatter Plots and Histograms
* Dashboard Export as HTML

---

# 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Plotly
* Jupyter Notebook

# 📂 Dataset Information

The dataset contains global COVID-19 statistics such as:

* Total Cases
* New Cases
* Total Deaths
* Total Recovered
* Active Cases
* Total Tests
* Population Data

Dataset Format: `CSV`

---

# 📊 Visualizations Included

## 1. Bar Chart

Displays top affected countries based on total cases.

## 2. Pie Chart

Shows country-wise death distribution.

## 3. Scatter Plot

Analyzes relationship between total cases and deaths.

## 4. Choropleth Map

Displays global COVID spread using an interactive world map.

## 5. Histogram

Shows distribution of COVID case counts.

## 6. Interactive Dashboard

Combines multiple visualizations into a single dashboard.
